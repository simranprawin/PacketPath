MODULE 05

TCP vs UDP

Compare the two major transport layer protocols.

🔒

TCP

Transmission Control Protocol

Connection-oriented
  • Reliable data delivery
  • Connection establishment required
  • Uses acknowledgements
  • Maintains packet order
  • Generally more overhead
Common uses

Web browsing, email, file transfer

⚡

UDP

User Datagram Protocol

Connectionless
  • No delivery guarantee
  • No handshake required
  • No acknowledgements by default
  • Packets may arrive out of order
  • Lower protocol overhead
Common uses

Live streaming, online gaming, DNS

Which one should you use?

TCP is useful when reliability and ordered delivery matter. UDP is useful when low latency and speed are priorities and the application can handle loss or recovery itself.
